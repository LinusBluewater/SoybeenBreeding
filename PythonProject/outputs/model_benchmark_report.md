# SoyNAM 多模型基准测试报告

## 实验设置

| 项 | 内容 |
|---|---|
| 数据 | SoyNAM: 5544 品种 × 4611 SNP |
| 目标 | yield 的 BLUP 育种值 (环境校正) |
| 拆分 | 按品种分组 60/20/20, train+val=4435, test=1109 |
| 调参 | 在 train+val 上 5-fold CV 网格搜索 |
| 评估 | 独立 test 集相关系数 r |

## 结论

### 1. XGBoost 最优，但优势很小
- XGBoost (0.7676) vs Ridge (0.7575)：+0.010
- 统计误差 SE ≈ (1-r²)/√n ≈ 0.013，**差异在一个标准误以内**
- 但 5-fold CV 一致支持 XGBoost（0.7484 vs 0.7397），证据方向一致
- 代价：训练 30 分钟 vs Ridge 5 秒（6000 倍）

### 2. 梯度提升 > 线性 > 核方法 > 神经网络
```
XGBoost (0.768) > ElasticNet (0.760) > Ridge (0.758)
  > RandomForest (0.742) >> SVR (0.597) > KernelRidge (0.545) > MLP (0.482)
  >>> CNN (-0.03 ~ -0.14, 完全失败)
```

### 3. 深度学习在此数据上系统性失败
- CNN 三种架构（13/417/699 参数）全部 r < 0，包括参数量远小于样本量的超小网络
- MLP (0.482) 也远低于线性模型
- **原因**：产量是加性多基因微效性状，线性模型匹配遗传结构；神经网络缺乏可学的非线性/交互结构

### 4. 方法已收敛
- XGBoost 精调：多组配置 CV 稳定在 0.748 附近，无进一步提升
- 特征固定（4611 SNP 芯片）下，**0.75-0.77 是该数据的精度上限**（遗传力 h²≈0.75）

## 实践建议

| 场景 | 推荐 |
|---|---|
| 追求最高精度、不介意训练时间 | XGBoost (test r=0.768) |
| 快速迭代、需要可解释性 | Ridge/ElasticNet (r=0.758-0.760, 秒级) |
| 不要使用 | CNN、MLP、SVR、KernelRidge |
